# ClipForge · encuadre seguro para entrevistas

- Añade muestreo de caras simultáneas antes de elegir el recorte vertical.
- En planos de diálogo con varias caras repetidas, conserva el plano completo sobre fondo desenfocado en vez de cortar a una sola persona.
- Mantiene seguimiento facial cuando el plano parece centrado en una sola persona.
- Si el seguimiento no está disponible o resulta ambiguo, usa el diseño de plano completo como fallback seguro.
- Añade pruebas unitarias para el umbral de ambigüedad multi-cara.
