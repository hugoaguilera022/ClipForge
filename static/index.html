01 / PRODUCCIÓN

Crear clips

Procesamiento local
O SUBE UN ARCHIVO

No necesitas preparar subtítulos: al generar, ClipForge extrae el audio por fragmentos y lo transcribe localmente con MLX Whisper en Apple Silicon, Faster-Whisper o whisper.cpp, compatible con macOS, Windows y Linux. La primera ejecución descarga el modelo seleccionado; después puede funcionar sin conexión. Si el motor local no está instalado o el modelo no se ha descargado, ClipForge mostrará un error explicativo; también puedes aportar un SRT/VTT. Con reconocimiento local se obtienen tiempos por palabra; un SRT/VTT externo puede contener solo tiempos por frase. En ese caso no se inventan tiempos palabra a palabra. OpenCV es opcional; si falta, se usa recorte central. La URL requiere yt-dlp (ligero, instalación opcional) y conexión a Internet; el análisis y render se realizan localmente. La descarga solo debe hacerse si tienes autorización para editar el vídeo.

Por qué algunas conexiones están pendientes

YouTube requiere OAuth; Instagram y Facebook requieren permisos de Meta y alojamiento temporal del vídeo; TikTok exige aprobación y auditoría para publicar públicamente. X puede requerir un plan de API de pago.

La publicación automática aún no está habilitada. Primero debemos registrar y aprobar las aplicaciones oficiales y proteger los tokens en un backend HTTPS.

MOTOR 01 / NAVEGADOR

Transcripción gratuita en el navegador

Sin API · sin subir el vídeo

Motor Whisper ejecutado en tu navegador mediante WebGPU o WASM. Base es el modelo recomendado: ofrece marcas de tiempo fiables y permite transcribir sin servicios de pago. Small sigue disponible como experimental; si no puede cargar o generar marcas de tiempo, ClipForge vuelve automáticamente a Base para conservar los cortes sincronizados. Después, un modelo multilingüe de embeddings (aprox. 113 MB) compara los temas de los candidatos para evitar clips repetidos; se descarga una vez, se guarda en la caché del navegador y trabaja localmente, sin API.

Descarga temporal mediante un servicio gratuito limitado; el análisis y la edición se realizan en tu navegador.
Debe ser un enlace directo al archivo y permitir CORS. Las páginas de YouTube no son enlaces directos de vídeo.
Cadena de proveedores IA gratuitos (opcional)

Añade tus propias claves gratuitas de Gemini, Groq, Cerebras, Mistral y OpenRouter. ClipForge rota las peticiones editoriales entre los proveedores configurados y pasa al siguiente si uno limita o falla. Las claves se guardan únicamente en el almacenamiento local de este navegador y se envían directamente al proveedor elegido. Cada servicio mantiene sus propios límites y condiciones; no se garantiza disponibilidad ni cuota.

Sin proveedores externos configurados: se utilizará el modelo local compatible. Consigue las claves en las páginas oficiales: Gemini · Groq · Cerebras · Mistral · OpenRouter. Usa únicamente planes que indiquen explícitamente coste 0.
Motor editorial IA gratuito en la nube (opcional)

Conecta una sesión temporal de Google Colab: usa Qwen3 8B si hay GPU suficiente y Qwen3 4B como alternativa. No necesita API de pago. La sesión gratuita puede desconectarse y no es ilimitada; si no está conectada, ClipForge intenta el motor local compatible.

Abrir y ejecutar el motor gratuito en Google Colab El token se conserva solo en esta pestaña y no se envía a ClipForge/Render. La URL y el token caducan al reiniciar Colab.

MOTOR 04 / EXPORTACIÓN LOCAL

Renderizar sin servidor

H.264 · MP4 · 1080 × 1920

Genera los cortes seleccionados directamente en este navegador. El vídeo no se sube. El detector facial abierto intenta seguir el rostro principal; si hay varias personas o no se puede detectar con seguridad, conserva el plano completo sobre un fondo difuminado. El análisis de imagen se ejecuta en tu navegador; el proveedor puede recibir métricas técnicas de uso, pero no los fotogramas del vídeo. Requiere un navegador actualizado con WebCodecs y conexión inicial para descargar el detector. Los MP4 se entregan juntos en un ZIP.

Formato de autorización requerido

Guarda un archivo con el mismo nombre del vídeo y el sufijo .clipforge.json. Debe incluir rights_confirmed: true, rights_holder y permission_reference. Consulta INBOX_MANIFEST.example.json.
